오늘은 진행 중인 프로젝트들의 배포 준비와 운영 기반 정리에 집중했다.

## 앱 인증/온보딩 플로우 정리

현재 개발 중인 앱에서 이메일 기반 인증 플로우를 정리했다.

이번 작업의 핵심은 사용자가 처음 앱에 들어와서 회원가입을 완료하고, 필요한 기본 정보를 입력한 뒤 자연스럽게 앱을 사용할 수 있도록 만드는 것이었다.

### 주요 작업

- 이메일 회원가입 구현
- 이메일 로그인 구현
- 이메일 인증 플로우 구현
- 비밀번호 재설정 기능 구현
- 회원가입 후 온보딩 플로우 추가
- 닉네임, 생일, 소속 선택 등 기본 정보 입력 화면 구성
- 가입 완료 후 환영 화면 추가

기존에는 로그인 여부 중심으로 신규 사용자를 판단했지만, 이번에는 온보딩 완료 여부를 기준으로 신규 사용자 여부를 판단하도록 수정했다.  
이렇게 하면 단순히 계정만 생성한 사용자와 실제 가입 절차를 끝낸 사용자를 더 명확히 구분할 수 있다.

## 앱스토어 제출 준비

앱 출시를 위해 필요한 기본 요건들도 함께 정리했다.

### 주요 작업

- 앱 표시명 정리
- iOS 권한 설정
- 개인정보처리방침 등 정책 링크 연결 준비
- 법적 고지용 정적 페이지 초기화

개발 기능을 구현하는 것과 별개로, 실제 스토어에 앱을 제출하려면 앱 이름, 권한 설명, 정책 페이지 같은 요소들도 필요하다.  
이번 작업을 통해 배포 전 체크해야 할 항목들을 하나씩 채워가고 있다.

## 블로그 운영 기반 개선

개발 기록을 더 안정적으로 관리하기 위해 블로그 쪽 작업도 진행했다.

### 방문자 분석 연결

블로그에 방문자 분석 도구를 연결했다.

- 분석 설정 추가
- 공통 head 영역에 분석 스크립트 삽입

이를 통해 앞으로 어떤 글이 많이 읽히는지, 어떤 페이지에 방문자가 들어오는지 확인할 수 있게 되었다.

### 스터디 랜딩 페이지 추가

진행 중인 스터디 활동을 소개하기 위한 전용 랜딩 페이지를 추가했다.

- 스터디 소개 페이지 생성
- 블로그 네비게이션에 페이지 등록
- 관련 이미지 자료 연결

단순히 글을 쌓는 블로그가 아니라, 진행 중인 활동을 외부에 보여줄 수 있는 공간으로 확장하는 작업이었다.

### 이미지 관리 자동화

블로그 글에 들어가는 이미지 경로 문제를 줄이기 위해 이미지 파이프라인도 정비했다.

- 이미지 경로 자동 교정 스크립트 추가
- 훅 설치 스크립트 추가
- 누락된 이미지 복구
- 이미지 파일명 정리

이미지 경로가 깨지면 글의 완성도가 크게 떨어지기 때문에, 반복적으로 발생할 수 있는 문제를 자동화로 줄이는 방향으로 정리했다.
